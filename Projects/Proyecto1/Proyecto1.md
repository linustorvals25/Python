## Proyecto 1 — Calculadora de consola

**Nivel: Básico**

**Conceptos**
* Variables.
* int, float, str, bool.
* Operadores aritméticos.
* Operadores de comparación.
* Entrada mediante input().
* Conversión de tipos.
* if, elif, else.
* Funciones simples.
* return.

**Conocimientos previos**

Ninguno.

**Qué construir**

Una calculadora ejecutada desde la terminal capaz de realizar operaciones matemáticas básicas.

**Funcionalidades**
* Suma.
* Resta.
* Multiplicación.
* División.
* Potencia.
* Módulo.
* Solicitar números al usuario.
* Mostrar el resultado.

**Retos opcionales**
* Menú interactivo.
* Detectar división entre cero.
* Permitir repetir operaciones.
* Añadir raíz cuadrada.
* Crear una función independiente para cada operación.
* Mostrar resultados con formato decimal configurable.

**Habilidades adquiridas**

Aprender el ciclo fundamental:

**entrada → procesamiento → salida**

y empezarás a separar lógica en funciones.
